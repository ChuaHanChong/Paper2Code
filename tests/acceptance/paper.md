## Method

Implement `scaled_dot_product_attention(query, key, value)` in `attention.py` using only the Python standard library.
Each argument is a nonempty rectangular two-dimensional list of finite real numbers.
The shapes are query `[n_queries, d_key]`, key `[n_keys, d_key]`, and value `[n_keys, d_value]`, with every dimension positive.
The return value is a new two-dimensional list of floats with shape `[n_queries, d_value]`; never mutate any input.
For query row i and key row j, compute score[i,j] = sum(query[i,k] * key[j,k]) / sqrt(d_key).
For each score row, subtract its maximum before taking exponentials, then normalize the exponentials to sum to one.
Compute output[i,t] = sum(weight[i,j] * value[j,t]).
No learned parameters, biases, masking, dropout, batching, training, data downloads, or external packages are part of this method.
Empty matrices, empty rows, ragged rows, mismatched query/key feature dimensions, and mismatched key/value row counts must raise ValueError.
Reject nonfinite numeric input with ValueError; the implementation must not return a successful result containing NaN or infinity.
